Matrix 功能

從號碼查找，
到版路探索。

同星、探索、天衡、天樞、天衍與天工，各有不同的比對條件。

Matrix 探索

依彩種、探索期數與加減、合值、拖牌等版路條件篩選歷史結果，展開查看驗證過程。

Matrix 同星

指定 2 至 3 個號碼與間隔期數，查找號碼出現的條件期，並對照指定間隔後的開獎結果。

Matrix 天衡

以同一期的兩個球位及其號碼為條件，比對歷史紀錄，整理符合條件的版路結果。

Matrix 天樞

以同一期的三個球位及其號碼為條件，比對歷史紀錄，整理符合條件的版路結果。

Matrix 天衍

固定十三期與完整範圍，以兩條規則組成複合版路；可展開結果查看驗證過程。

Matrix 天工

固定五十期、二段式與準 2 進 3，依等距來源、球位走向及兩段版路規則定位結果。
