# Matrix 探索頁排列與比例調整設計

## 目的

依使用者提供的 4 張示意圖，調整既有 Matrix 探索頁的區塊排列與元件比例。此次只處理版面結構與尺寸比例，不修改功能、文案、資料邏輯或操作流程。

## 執行範圍

採用使用者確認的「B + C」：

- B：重排現有區塊順序。
- C：同步調整現有元件比例，使版面更貼近示意圖。

## 固定排列

由上到下：

1. 探索設定
   - 彩種
   - 探索期數
   - 版路類型
2. 命中條件
   - 準4+（鎖定1碼）
   - 準5+（鎖定2碼）
   - 進階探索設定入口
3. 進階探索設定展開內容
   - 號碼順序
   - 探索日期
   - 探索範圍
4. 開始探索
5. 近10期開獎號碼
   - 標題
   - 查看更多紀錄
   - 表格
6. 重複號碼統計
7. 免責文字
8. 探索結果區
   - 連準篩選
   - 符合條件版路數量
   - 結果表格

## 版面調整原則

- 手機主畫面左右安全邊距維持 12px。
- 以既有正式元件為基礎調整，不重新設計元件。
- 卡片內距、欄位寬度、按鈕高度、表格欄位比例依示意圖調整。
- 近10期表格維持既有彩種與彩球規則。
- 重複號碼統計採示意圖的多欄緊湊排列。
- 探索結果區維持既有功能與資料，只調整排列與比例。

## CSS / 樣式處理規則

- 先定位目前 Matrix Explore 正式生效的樣式來源。
- 若同一效果存在重複 CSS、inline style、`!important`、負值位移、重複 media query 或補償性強制定位，只移除與本次排列衝突或已失效的規則。
- 不新增第二套覆寫來蓋掉舊規則。
- 不解除仍負責正常手機適配、比例、對齊的必要限制。
- 最終每個尺寸、間距、位置效果應只保留單一有效控制來源。

## 不修改項目

- 不新增功能。
- 不新增文字。
- 不修改既有功能流程。
- 不修改資料來源或演算法。
- 不修改其他頁面或其他元件。
- 不改品牌、Logo、底部導覽。

## 驗收

完成後需確認：

- 390px 手機直式畫面左右邊距正確。
- 各區塊順序與本設計一致。
- 元件比例貼近示意圖。
- 無文字碰撞、按鈕碰撞、彩球碰撞或卡片重疊。
- 表格不被裁切、不異常拉伸。
- 不存在本次修改新增的補償性覆寫。
- 其他頁面不受影響。
