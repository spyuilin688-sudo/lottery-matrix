# Matrix 探索手機 Responsive／Layout 整理設計

## 範圍
只整理 Matrix 探索主頁的手機版 Responsive／Layout。保留現有文案、功能、資料邏輯、操作流程、區塊順序、正式標題圖與底部導覽，不重新設計其他頁面。

## 已確認處理方向
- 探索設定與進階探索設定由固定 110px + 222px 欄寬改為可縮放的兩欄版面，維持 12px 頁面左右內距。
- 設定控制元件使用容器可用寬度，不再鎖定 222px。
- 三等分選項在較窄手機寬度允許原文字於按鈕內正常換行，避免文字互相覆蓋或超出右側。
- 近10期標題保留原文，移除造成右側裁切的強制不換行限制。
- 近10期表格重新分配期數、日期、開獎號碼欄寬，優先保證 6+1 彩球與特別號完整顯示。
- 移除 Matrix 探索近期開獎中六合彩彩球 26px 的衝突尺寸鎖定，回到既有 6+1 共用 23.5px 正式尺寸；保留六合彩素材比例與底線位置規則。
- 清除同一效果的重複固定寬度／重複 selector，不新增第二套覆寫。

## 不修改
- Matrix 天衍與 Matrix 天工的功能流程與文案。
- 其他頁面。
- 彩球號碼格式、彩種資料、API 與探索演算法。
- Logo、標題素材與底部導覽。

## 驗證
- 390px 與較窄手機寬度下，探索設定、進階設定、近10期標題、539 五球及六合彩／大樂透 6+1 均不得水平溢出。
- 近10期特別號必須完整可見。
- 重複號碼統計與探索結果區維持既有結構。
- 執行 Matrix 探索／近期開獎相關測試、完整測試與 build。
