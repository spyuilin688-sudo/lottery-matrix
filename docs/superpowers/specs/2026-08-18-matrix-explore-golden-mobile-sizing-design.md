# Matrix 探索｜行動端黃金尺寸版面規格

## 範圍
只修改 Matrix 探索主頁的介面排列與尺寸來源。保留既有文案、功能、資料邏輯、操作流程、區塊順序、正式標題圖與底部導覽，不修改其他頁面。

## 頁面與區塊尺寸
- 頁面左右安全邊距：12px。
- Section 內部四周 padding：8px。
- Section 與 Section 上下 gap：8px。
- 表單上下列 gap：8px。
- 同一行內按鈕、標籤、輸入框之間的水平 gap：8px。

## 控制元件高度
- 一般選項按鈕：24px。
- 下拉選單：24px。
- 輸入框：24px。
- 核心大按鈕（包含開始探索）：32px。

## 字級
- 板塊大標題：15px，Bold。
- 按鈕文字、表格核心數據：13px。
- 次要說明、日期、欄位名稱：11px。

## 排列方式
- 使用現有 Matrix 探索 DOM／React 結構能直接承接的 Flexbox／Grid 進行排列。
- 不改變現有區塊順序。
- 不新增未確認元件、文字、按鈕、狀態或功能。
- 僅調整 Matrix 探索相關的正式控制來源。

## 禁止樣式
Matrix 探索此次調整不得新增或使用：
- 發光效果。
- box-shadow。
- text-shadow。
- 漸層。
- 粗邊框。
- 補償性負 margin。
- translate／transform 硬拉定位。
- 新增 !important 覆寫。
- 第二套重複 selector／media query 作為補丁。

## 清理規則
- 若同一效果已有多層 CSS、inline style、!important、固定尺寸或 media query 互相覆寫，先確認目前正式控制來源。
- 僅移除已失效、重複、或與本次規格衝突的 Matrix 探索規則。
- 仍負責正常版面、比例、對齊與手機適配的必要規則必須保留。
- 不以新增覆寫掩蓋舊問題。

## 驗證
- 主要手機直式畫面左右維持 12px。
- Section 內距與區塊／欄位 gap 均為 8px。
- 一般控制元件實際高度 24px，開始探索為 32px。
- 15px／13px／11px 字級依本規格套用。
- 無文字碰撞、控制元件碰撞、水平溢出或裁切。
- Matrix 探索功能流程與資料行為保持不變。
- 其他頁面不得因本次修改產生視覺或功能變更。
