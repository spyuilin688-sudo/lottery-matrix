# Matrix 探索結果介面調整設計

## 基準與範圍

- 以 `main` 的 `284c54bd00ea8c4d587547445aed46664e3930ee` 為分支基準。
- 只修改 Matrix 探索的開始探索狀態、探索結果分頁、重複號碼統計，以及版路展開後的摘要、驗證過程與本期預測卡片。
- 沿用現有 V12 Matrix API 回應，不修改 Supabase RPC、資料庫、演算法或結果內容。
- 不修改 Matrix 天衍、天工及其他頁面的功能與樣式。

## 開始探索後的狀態

點擊「開始探索」時，在送出探索請求前同步執行：

- 「同碼」重置為未選取。
- 已點選的重複號碼篩選清除。
- 「連準篩選」的選取值恢復為目前命中條件的預設值。
- 準4+（鎖定1碼）的預設值：準5進6、準6進7、準7進8。
- 準5+（鎖定2碼）的預設值：準7進8、準9進10、準11進12。
- 本次 API 請求直接使用重置後的預設值與 `sameCode: false`，避免畫面狀態與請求條件不同步。

## 探索結果分頁

- 前端將 V12 API 回傳的探索結果切成每頁最多 30 筆，不變更 API 回應與探索總筆數。
- 沿用專案既有的上一頁、頁碼／總頁數、下一頁分頁樣式。
- 首次探索及任何會重新取得探索結果的條件變更，都回到第 1 頁。
- 「探索到 N 組符合條件版路」繼續顯示完整結果總數，不改成當頁筆數。
- 空結果維持現有「無符合設定條件」內容。

## 重複號碼統計

- 號碼小卡的號碼由金色改成白色。
- 次數文字、卡片外框、選取與互動行為維持現況。

## 版路摘要與分隔線

- 展開版路後，上方分隔線至「版路摘要」卡片的間距為 6px。
- 「本期預測卡片」下方保留 6px 間距，再顯示下方分隔線。
- 上、下兩條分隔線與驗證卡外框共用同一個既有外框色值，避免顏色漂移或重複覆寫。
- 版路摘要文字在目前正式字級基礎上增加 3px。
- 摘要卡片不設定固定高度；文字需要換行時由內容自動撐高，並保留右上角連準標籤空間。
- 每個摘要分隔符號前後各增加一個半形空格，呈現為 ` ｜ `。

## 驗證過程欄位

- 左、中、右三欄及目前列高維持不變。
- 右欄公式的左右內距由 6px 縮至 3px，字級改為 `clamp(8px, 2.2vw, 10.5px)`；不修改驗證列高變數。
- 六合彩與大樂透的中欄開獎號碼，在第六顆正碼與第七顆特別號之間加入「+」。
- 「+」沿用現有特別號分隔色 `#d4a63b`，不改變號碼本身的狀態顏色。

## 拖牌與同期驗證列

當版路類型為「拖牌」，或驗證範圍為同期（`referenceOffset` 未提供或為 `0`）時：

- 鎖定來源與驗證來源合併在同一列，不再各自產生一列。
- 第一列顯示期數、完整開獎號碼與第一個驗證公式。
- 號碼只使用「鎖定條件」的顏色狀態；不顯示驗證號碼或命中號碼的其他顏色狀態。
- 開獎結果列保留號碼內容，但不標示命中狀態。
- 若同一組只有一個驗證值，呈現合併列與開獎結果列。
- 若同一組有兩個驗證值，在合併列後新增一列：左欄空白、中欄空白、右欄只顯示第二個驗證公式；開獎結果列排列在其後。
- 非拖牌且非同期的版路維持鎖定列、驗證列、開獎結果列三列結構。

## 本期預測卡片

- 「本期預測」文字在現有字級基礎上增加 6px。
- 預測號碼在現有字級基礎上增加 6px。
- 卡片不設定固定高度，由放大後的文字與既有內距自動撐高。
- 左右箭頭、文字內容與預測號碼資料維持不變。

- `src/FeaturePages.tsx`：開始探索重置、30 筆分頁、特殊驗證列、特別號分隔符號及摘要空格。
