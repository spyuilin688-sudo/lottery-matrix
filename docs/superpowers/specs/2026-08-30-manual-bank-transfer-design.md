# Matrix Pro 手動轉帳與會員開通設計

日期：2026-08-30  
狀態：已確認

## 目標

在尚未串接金流 API 前，保留 Matrix Pro 的方案、付款、續訂、自動續訂與付款紀錄入口，先提供銀行轉帳、末五碼提交及管理後臺手動開通流程。

## 會員方案

| 方案 | 金額 | 使用天數 |
|---|---:|---:|
| 月方案 | NT$1,880 | 30 天 |
| 季方案 | NT$4,580 | 90 天 |
| 年方案 | NT$16,800 | 365 天 |

## 銀行資料

銀行資料只在使用者選擇方案並按下「確定付款」後的轉帳頁面顯示。

| 欄位 | 內容 |
|---|---|
| 銀行 | 連線銀行 |
| 銀行代碼 | 824 |
| 帳號 | 111023004501 |
| 戶名 | 黎小姐 |

帳號右側提供「複製」按鈕，按下後複製完整帳號。

## 使用者流程

1. 使用者登入會員。
2. 選擇月方案、季方案或年方案。
3. 使用者按下「確定付款」。
4. 系統開啟轉帳頁面。
5. 轉帳頁面顯示所選方案、金額及銀行資料。
6. 使用者完成網銀轉帳。
7. 使用者只輸入轉出帳號末五碼。
8. 系統提交申請並由伺服器記錄提交時間。
9. 頁面顯示申請為「待確認」。
10. 管理後臺確認後，系統開通或延長對應方案。
11. 管理後臺拒絕後，不開通或延長方案。

## 重複提交限制

同一會員同一時間只允許一筆「待確認」申請。

會員已有「待確認」申請時：

- 頁面禁止再次提交。
- 伺服器拒絕再次建立申請。
- 顯示「已有待確認申請」。

申請經管理後臺確認或拒絕後，會員才能再次提交。

## 管理後臺

轉帳申請紀錄顯示：

- 會員
- 方案
- 金額
- 帳號末五碼
- 系統提交時間
- 狀態

待確認申請提供：

- 確認
- 拒絕

確認後：

- 建立付款紀錄。
- 開通或延長所選方案。
- 手動轉帳不啟用自動續訂。

拒絕後：

- 更新申請狀態。
- 不建立付款紀錄。
- 不開通或延長方案。

## 付款紀錄

會員付款紀錄頁顯示自己的紀錄，包括：

- 方案
- 金額
- 系統提交時間
- 狀態

## 保留項目

以下頁面與按鈕保留：

- 會員方案
- 付款
- 續訂
- 自動續訂
- 付款紀錄

自動續訂在尚未串接金流 API 前顯示不可使用，不執行自動扣款。

## 手機畫面

- 方案頁只顯示方案及「確定付款」按鈕，不顯示銀行資料。
- 按下「確定付款」後開啟轉帳頁面。
- 轉帳頁面顯示所選方案、金額、銀行資料及末五碼輸入。
- 帳號與「複製」按鈕同列呈現。
- 畫面寬度不足時，銀行資料維持可完整閱讀。
- 提交按鈕在末五碼未滿五位時不可提交。
- 已有待確認申請時，顯示狀態並禁止再次提交。

## 資料處理

- 會員身分以登入會員為準，不由頁面自行指定。
- 方案與金額以系統方案資料為準。
- 帳號末五碼必須為五位數字。
- 提交時間由伺服器產生。
- 確認與拒絕只由管理後臺執行。
- 確認開通、付款紀錄建立及申請狀態更新需一次完成。

## 錯誤處理

| 情況 | 結果 |
|---|---|
| 未登入 | 不可提交 |
| 末五碼不足五位或不是數字 | 不可提交 |
| 已有待確認申請 | 顯示「已有待確認申請」 |
| 提交失敗 | 不建立申請，顯示提交失敗 |
| 已處理的申請再次確認或拒絕 | 不重複處理 |

## 驗證

- 方案頁不顯示銀行資料。
- 選擇方案並按下「確定付款」後才開啟轉帳頁面。
- 轉帳頁面顯示所選方案與正確金額。
- 月、季、年方案與金額正確。
- 銀行、代碼、帳號及戶名正確。
- 複製按鈕可複製完整帳號。
- 末五碼只接受五位數字。
- 提交時間由伺服器記錄。
- 同一會員無法同時建立兩筆待確認申請。
- 管理後臺確認後正確建立付款紀錄並開通或延長方案。
- 管理後臺拒絕後不建立付款紀錄、不開通方案。
- 手動轉帳不啟用自動續訂。
- 會員只能查看自己的申請及付款紀錄。
- 手機畫面可完整操作。
