# Matrix 探索設定視覺層級設計

## 範圍

只修改 Matrix 探索主頁的「探索設定」與「進階探索設定」區塊樣式，以及「命中條件」按鈕樣式。不修改功能、資料、文案、操作流程或其他頁面。

## 已確認規格

- 「探索設定」與「進階探索設定」的三個左側功能圖示由 `32px` 縮小 10% 為 `28.8px`。
- 左側標籤欄最小寬度同步減少 `3.2px`：一般寬度由 `92px` 改為 `88.8px`；`min-width: 40rem` 由 `108px` 改為 `104.8px`。
- 兩區三列圖示的垂直間距由 `5px` 改為 `7px`。
- 「彩球類型／探索期數／版路類型」維持現有主要文字層級。
- 下拉框與選項按鈕作為第二視覺層級。
- 已選按鈕維持目前金色文字、金色邊框與微弱金色背景。
- 未選按鈕使用白灰文字、深灰金邊框及無亮色背景。
- 卡片外框維持 `#755329`；未選按鈕邊框亮度低於卡片外框，已選按鈕維持目前金色。
- 「命中條件」兩個按鈕使用完全相同的寬度、高度與內距。
- 「進階探索設定」字重改為 `600`；「命中條件」標題維持 `700`。

## 響應式限制

- 保留控制區 `min-width: 0` 與 `flex: 1 1 0` 的流動配置。
- 不新增 `!important`、負邊距、固定總寬、`zoom`、`transform` 補償或額外尾端覆寫。
- 驗證 `360px`、`375px`、`390px` 視口寬度不產生水平溢出。
