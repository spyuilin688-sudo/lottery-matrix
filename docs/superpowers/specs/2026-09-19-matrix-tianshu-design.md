# Matrix 天樞

基準：`spyuilin688-sudo/lottery-matrix`，main `f5c37f53b77d3dd5b00a552d8ab54256a6e5b3b5`。

使用者要求：新增「天樞」演算法；相較天衡，唯一規則差異為同一期鎖定條件由兩碼變成三碼。新頁面的卡片、按鈕、選項、尺寸、間距與其他規則完全比照天衡。

以目前天衡程式為準，延伸如下：
- 同一期球位依序取三個不重複位置及其號碼；五球共10組，七球共35組；不重複反向排列。
- 歷史回推三個球位與三個號碼必須同時一致；同期驗證排除這三個鎖定位置。拖牌仍使用最前鎖定位置。
- 沿用三期／十三期、四彩種與排序、標準／完整範圍、三種版路、現有連準規則及預設選項；規則數量的「鎖定1碼／鎖定2碼」維持原意。
- 重用天衡頁面及驗證元件，新增第三個鎖定位置及號碼；頁名、按鈕和導覽辨認為天樞。不得增加新視覺資產或重設樣式。
- 獨立 `tianshu` 成品與 `matrix_tianshu_results`，列表／驗證 RPC 分別為 `matrix_tianshu_list`、`matrix_tianshu_validation`；沿用既有權限、租約、三日保存與清理。
- 同一次分析加入天樞階段，保留既有 Matrix 狀態來源與規則。

跨層資料契約：沿用天衡欄位，新增必填 `thirdNumber`（兩位字串）、`thirdLockedPosition`（大於第二位置），資料庫為 `third_number`、`third_locked_position`；驗證 `lockedPositions`／`lockedNumbers` 各有三項；回應 kind 為 `tianshu`。天衡雙碼既有資料及結果 ID 不變。

驗收：三碼全匹配、三碼內容完整、分批與復原一致、列表與驗證同版、未登入限制與天衡一致；天衡相關回歸通過；手机320／390px無新增水平溢出、桌面與天衡介面一致。依 AGENTS.md 限定測試檔案；不執行全量測試。正式合併與部署另行確認。
