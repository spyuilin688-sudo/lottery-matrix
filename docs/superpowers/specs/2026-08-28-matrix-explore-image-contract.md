# Matrix Explore 圖像演算法契約

日期：2026-08-28

## 目的

以使用者提供的 15 張已驗證版路截圖，固定 Matrix Explore 的最小數學與時間契約，並防止不同時間邊界、不同運算族或非法候選被混合後造成結果爆量。

## 固定模型

一條版路固定以下欄位：彩種值域、順球或落球、鎖定號碼與位置、精確參照期位移、精確參照位置、運算族、完整規則常數集合，以及相對鎖定來源期的預測距離。

- 鎖定來源期：指定號碼必須在指定球位。
- 參照期：`source + referenceOffset`，上 N、同期、下 N 都是精確位移，不是掃描範圍。
- 結果期：`source + predictionDistance`，永遠相對鎖定來源期，不相對參照期。
- 命中：任一候選出現在結果期號碼集合即可；結果位置不必等於來源或參照位置。
- `準 q 進 q+1`：q 個已完成歷史驗證組皆至少命中一碼；待驗的第 q+1 組不計入 q。同組雙命中仍只算一組。

## 運算

### 加減

對值域 `1..M` 做一次循環加法：`normalize(base + rule, M)`。

- `+a+b` 是兩個常數分別套用同一個 base，不是連加、排列組合或遞迴閉包。
- `+0` 若參照期／位置與鎖定來源不同，仍是 `加減:0`；不得改標成拖牌並改用鎖定號碼作 base。
- 若加減的參照期與位置恰等於鎖定來源與位置，該設定由拖牌族負責，加減族不重複產生。

### 拖牌

拖牌只用同期、同一鎖定位置的號碼作 base；每個固定常數各產生一個候選。`+0` 在此族代表原號碼。

### 合值

`base 合 C = C - base`。只保留 `1 <= C - base <= M` 的候選；非法差值直接省略，禁止用 modulo 回捲。

## 探索日期與期數邊界

歷史陣列以最新一期為 index 0。對 artifact 的 `exploreDateOffset = o`、鎖定來源 index `s`：

- 相對來源 index 為 `r = s - o`。
- 只有 `0 <= r < explorePeriods` 才屬於該 2／7／13 期選項。
- 該選項的同一目標邊界只接受 `predictionDistance = r + 1 = s - o + 1`。

因此同一 raw result 不得僅因來源落在窗口內，就複製到所有本日／昨日／前日選項。每個來源只需計算能對應三個日期邊界的距離，並限制在 1..13。

## 儲存與讀取契約

Supabase RPC 直接讀取 chunk JSONB 的 `items` 與 `validationById`。Railway 寫入的 chunk 必須保留這兩個可查詢欄位；不得寫成 RPC 無法解碼的 application-level `zlib+base64` envelope。

演算法修正使用新的 analysis version，避免已完成的舊版本阻止重算或被誤當成新契約結果。

## 非目標

- 不改頁面視覺、欄位、導航或權限。
- 不以這批 Explore 截圖推翻既有六合彩／大樂透第七位置支援；特別號是否參與的產品規則另案處理。
- 不改天衍、天工的數學定義；本次只修正這批圖片可直接證明的 Explore 契約及其 Railway→Supabase 邊界。
