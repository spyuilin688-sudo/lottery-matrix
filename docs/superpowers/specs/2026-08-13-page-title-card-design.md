# 頁面標題卡設計規格

## 修改目標

將目前有標題的頁面標題改為卡片形式，並只在已確認的頁面把既有操作放入同一張標題卡右側。

## 共用規則

- 左側顯示目前頁面標題。
- 未指定右側操作的其他標題頁面，只顯示標題卡，不新增操作。
- Logo、返回鍵、頁面內容、功能流程與其他未指定區域保持不變。
- 使用同一套正式標題卡元件，不新增第二套樣式控制來源。
- 若現有標題樣式或位置規則衝突，移除舊規則後修改正式來源，不追加覆寫。
- 以 390px 手機直式畫面檢查，不得溢出、重疊或擠壓標題。

## Matrix 探索／天衍／天工

- 標題卡左側顯示目前頁面標題。
- 右側顯示「探索」「天衍」「天工」三個切換按鈕。
- 當前頁按鈕顯示選取狀態。
- 點擊其他按鈕切換至既有對應頁面。
- 不修改三個頁面既有功能與內容。

## 歷史開獎號碼

- 標題卡左側顯示「歷史開獎號碼」。
- 右側依序顯示彩種下拉選單與「篩選條件」。
- 彩種下拉選單沿用四個既有彩種：
  - 今彩539
  - 天天樂
  - 六合彩
  - 大樂透
- 「篩選條件」完整保留既有內容：
  - 期數
  - 年／月／日
  - 號碼順序
  - 1000期／3000期／5000期／所有期數
  - 重設
  - 開始探索
- 不刪除或修改既有篩選功能與資料查詢邏輯。

## 其他標題頁面

- 僅將標題改為卡片形式。
- 不將其他操作移入卡片。
- 不新增按鈕、文字、功能或互動。

## 驗收條件

- 所有原本有標題的頁面均使用同一套標題卡。
- Matrix 三個頁面的切換按鈕能進入既有對應頁面。
- 歷史開獎號碼可透過下拉選單切換四個彩種。
- 歷史開獎號碼的排序與歷史範圍功能保持原有結果。
- 390px 寬度下標題與右側操作不碰撞、不換出卡片範圍。
- 未指定頁面的內容、位置與功能保持不變。
