# Matrix Explore 緊湊型手機版設計規格

## 目標
只調整 Matrix 探索頁 Logo 以下的 UI 尺寸、密度、間距與排列，使手機直式畫面在不改變功能、流程、文案、顏色與結構的前提下，同一螢幕可看到更多內容，並維持可讀性與操作性。

## 固定不變
- Repository：lottery-matrix
- Branch：main
- Logo／整合標題圖片不修改。
- 全頁左右外距固定 12px。
- 已確認的 8px 間距保持不變。
- 底部導覽不修改。
- 功能、流程、文案、資料邏輯、顏色、區塊順序與元件結構不修改。
- 不使用 scale、zoom、translate、負 margin、!important 或新增第二套覆寫。
- 只修改目前正式生效的尺寸與排版來源；若發現重複、失效或衝突規則，先清除舊來源，再修改正式來源。

## A｜偏緊湊方向
### 卡片
- 維持目前寬度與左右 12px 外距。
- 主要縮減上下 padding 與非必要垂直留白。
- 不改邊框色、背景、圓角視覺語言。

### 區塊標題
- 統一成較緊湊的字級、行高與左側金色標記比例。
- 維持目前字重、顏色與對齊。
- 第一張探索設定卡片已存在的縮小方向納入整頁一致化，不再讓第一張與後續區塊密度落差過大。

### 設定列／進階設定
- 降低每列高度。
- 文字、圖示、下拉框保持垂直置中。
- 下拉框與選項按鈕統一為較矮的手機緊湊尺寸。
- 小圖示保持清楚辨識，不因整體緊湊化而縮到難辨識。

### 命中條件／開始探索
- 命中條件按鈕縮短高度與內距，但維持原本兩欄排列與文字。
- 開始探索按鈕維持全寬，只縮減高度、字級、圖示與內距到一致緊湊層級。

### 近10期開獎號碼
- 縮減標題列、資料列高度與內距。
- 縮減文字、彩球與球間距，但保留兩位數顯示與既有彩球視覺規則。
- 539／天天樂 5 球、六合彩／大樂透 6+1 都必須完整顯示，不可橫向溢出或裁切。

### 重複號碼統計／探索結果
- 縮減卡片 padding、標題高度、統計格高度、內距與字級。
- 保持資訊層級與原本欄位排列。
- 不新增或刪除資訊。

### 卡片間距
- 使用目前既有正式 gap / margin 來源整理。
- 不用負 margin、position、transform 或補償性位移。

## 驗收條件
- 手機直式下沒有文字碰撞。
- 圖示不碰撞、不裁切。
- 539／天天樂／六合彩／大樂透彩球皆完整顯示。
- 6+1 不超出可視寬度。
- 卡片不重疊。
- 底部導覽不遮擋內容。
- 沒有異常留白。
- 沒有因舊規則再次覆寫新尺寸。
- 探索頁各區密度一致，且比目前正式版更緊湊。
- 其他頁面不受影響。

## 工程限制
- 修改前以 main 最新版本為唯一基準。
- 檢查 CSS、class、style、inline style、!important、固定寬高、min/max-width、min/max-height、position、top/bottom/left/right、transform、margin、padding、overflow、z-index、aspect-ratio、flex/grid、media query、JS/TS 動態樣式、條件式樣式、舊元件覆寫、重複規則與衝突規則。
- 僅移除已失效或與目前探索頁尺寸控制衝突的規則。
- 不為清理而解除其他必要限制。
- 不修改其他頁面或其他功能。
