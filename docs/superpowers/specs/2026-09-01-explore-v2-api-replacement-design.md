## 核心元件責任

### `HistoryIndex`

- 輸入同一彩種、同一排序模式的完整歷史。
- 以 `lottery + sortMode + position + number` 建立 occurrence index。
- 同一鎖定條件只取得一次 B、C、D、E…。
- 不得設定 30、80、100 或其他完整歷史總量上限。

### `SourceBatch`

- 每個彩種／排序模式一次建立十三個來源期。
- 今彩539：65 個鎖定條件；順球、落球分開建立。
- 天天樂：65 個鎖定條件；只建立順球。
- 六合彩：91 個鎖定條件；順球、落球分開建立。
- 大樂透：91 個鎖定條件；順球、落球分開建立。
- 二期、七期、十三期不得各自重新計算。

### `FullRangeCellBuilder`

- 每個 occurrence 只建立一次上1～14、同期合法位置及合法下方位置。
- 結果期不得建立為驗證 cell。
- locked cell 不得進入加減／合值範圍。
- 上1～7、同期合法位置與合法下方位置標記 `STANDARD_AND_FULL`。
- 上8～14標記 `FULL_ONLY`。
- 同一份 cell 同時計算加減與合值候選。

### `DragCandidateBuilder`

- 只讀 occurrence 的 locked cell。
- 不建立上1～14、同期其他位置或下方 range cells。

### `ScopeEvaluator`

- 完整範圍使用全部基礎候選。
- 標準範圍從同一批基礎候選排除 `FULL_ONLY`。
- 兩個範圍各自判定共同值、完整延續、最長連準、規則數與最終有效性。
- 不得將完整範圍 final result 刪除上8～14證據後當作標準結果。

### `StreakStateMachine`

- 依 v2 第 11～23 節分別處理鎖定一碼與鎖定兩碼。
- 候選必須依 B、C、D、E…逐組增量延續。
- 中途候選數量不得作為最終超過兩值的判定。
- 超過合法最大連準時整條無效，不得截短。

### `ResultFinalizer`

- 僅接受完成所有有效性判定的候選。
- 執行規則數、去重、格式化及固定排序。
- 只有 final result 與其 validation 可寫入 artifact／資料表。

## API 防爆不變條件

- 完整歷史不得以固定 N 期取代。
- 十三來源期只計算一次。
- occurrence index 只建立一次並重用。
- 拖牌、加減、合值不得各自重新搜尋 B、C、D…。
- 同一 occurrence 的完整 range cells 只建立一次。
- 加減與合值共用完整 range cells。
- 標準與完整共用基礎 cell／候選計算。
- 使用 Set／bitset、intersection、incremental state、early stop、lazy evaluation。
- 禁止展開 `所有 occurrence × 所有 cell × 所有候選值 × 所有共同值 × 所有 pair`。
- 禁止把超過兩個相同最長值展開為兩兩組合。
- 中間候選不得寫入 `matrix_explore_results` 或任何 final artifact。
- 只有完成整條驗證且合法的結果可持久化。

## Artifact、RPC 與分析版本

- 探索 artifact 保持現有 list 與 validation 對外欄位。
- Matrix 狀態繼續使用同一探索 artifact。
- Worker analysis version 與 `matrix_explore_list`、`matrix_explore_validation` 查詢版本必須同步。
- 新版本必須重新計算，不能沿用舊演算法已完成的 progress 或 artifact。
