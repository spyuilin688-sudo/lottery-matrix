# Matrix 探索版路展開排版設計

## 範圍
只修改 Matrix 探索「探索結果 → 版路類型」展開後的驗證內容。未展開的探索結果列表及其他頁面不修改。

## 已確認排版
- 保留目前展開後上方摘要內容；不恢復「條件摘要」四字。
- 連準次數維持摘要框右上角。
- 驗證資料每組固定 3 列。
- 每組左側顯示期數與完整開獎號碼。
- 對應號碼以框線標示。
- 每組右側集中顯示計算式與結果，不再讓每一列各自擁有一個右側公式格。
- 每組之間使用分隔線。
- 最後一組下方顯示「本期預測」與預測號碼。
- 排版依使用者提供參考圖還原，不新增其他功能、條件、文字或流程。

## 修改來源
- `src/FeaturePages.tsx`：調整 `RoadValidationProcess` 展開內容 DOM 結構。
- `src/feature-pages.css`：修改既有 `.road-validation-*` 正式樣式來源，不追加第二套覆寫。

## 驗證
- 手機直式確認三列資料、左右欄、分隔線與本期預測正常顯示。
- 確認未展開的探索結果列表不受影響。
- 執行既有測試與 build，確認無新增錯誤。
