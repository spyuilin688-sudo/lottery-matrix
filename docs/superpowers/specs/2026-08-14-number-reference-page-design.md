# 號碼對照單頁面調整設計

日期：2026-08-14

## 範圍

只修改「號碼對照單」頁面，不改動其他頁面、既有探索資料邏輯或列表標記功能。

## 頁首

- 標題卡圖片替換為 `/assets/lottery/functions/matrixHH.png`。
- 樂彩 Logo、返回鍵與標題卡固定於頁面上方。
- 樂彩 Logo 與標題卡的垂直間距為 8px。
- 標題卡左右邊距為 4px。
- 標題卡右側加入「刷新」與「收合鍵」。
- 「刷新」與「收合鍵」間距為 6px。
- 刷新功能沿用目前既有刷新行為。

## 查詢條件收合

收合範圍固定包含：

1. 彩種
2. 期數
3. 號碼順序
4. 三個號碼輸入框
5. 開始探索按鈕

- 點擊標題卡內的收合鍵，可切換展開與收合。
- 點擊「開始探索」後，查詢條件自動收合。
- 探索完成後，頁面自動捲動至列表最下方。

## 列表順序

- 不反轉既有資料排列。
- 最新期數位於列表最下方。
- 使用者由最下方向上查看較舊期數。

## 號碼輸入

- 每個輸入框只接受 01～49。
- 輸入 1～9 後，自動補為 01～09。
- 00、超過 49 或非數字內容不得成為有效輸入值。
- 保留目前三個輸入框與既有探索觸發方式。

## 選項顯示

- 修正「今彩539」與下拉符號無法完整顯示。
- 修正「1000期」與下拉符號無法完整顯示。
- 不修改選項內容與功能。

## 列表樣式

- 縮減列表標題列的上下高度。
- 列表內號碼字級在目前基礎上放大。
- 列表內期號與開獎號碼套用等寬數字，避免不同數字組合出現寬度差異。
- 保留既有欄位、分隔線、標記狀態與點擊功能。

## 手機畫面

- 以 390px 直式手機畫面為基準。
- 固定頁首不得遮住查詢條件或列表。
- 標題卡與內容不得超出手機畫面左右邊界。

## 驗收

1. 顯示 matrixHH.png 標題卡。
2. 頁首固定且 Logo 下方間距為 8px。
3. 標題卡左右邊距為 4px。
4. 刷新與收合鍵位於標題卡右側，間距 6px。
5. 查詢條件可正常展開與收合。
6. 開始探索後自動收合並捲到列表最下方。
7. 最新期數位於最下方。
8. 1～9 自動補零，輸入值限制在 01～49。
9. 今彩539與1000期文字、下拉符號完整顯示。
10. 標題列高度縮減，列表數字放大且等寬。
11. 既有探索、刷新、列表標記功能仍可使用。
