# Matrix Explore Correct Algorithm Specification

來源：使用者於 2026-08-30 上傳的 `今彩539.docx`。

## 適用範圍

- Matrix 探索：加減、合值、拖牌。
- 鎖定1碼與鎖定2碼。
- 本規格不定義天衍與天工演算法。

## 鎖定條件與預測期

- 探索二期共有 10 個鎖定條件。
- 最近一期的 5 個球位，各自固定預測下1期。
- 再前一期的 5 個球位，各自固定預測下2期。
- 同一來源不得再搜尋下1期至下13期。
- 七期與十三期依相同順序，來源相對位置分別固定為下1期、下2期……。

## 驗證範圍

鎖定球位為 `p`、預測期為下 `h` 期時，完整範圍包含：

- 上1至上14期，每期全部球位。
- 同期除鎖定條件本身以外的球位。
- 下1至下 `h-1` 期，每期全部球位。
- 加減與合值不得包含鎖定條件本身。
- 拖牌只使用鎖定條件本身。

今彩539每個鎖定條件的完整範圍座標數為 `5h+69`；下1期為74個，下2期為79個。

## 歷史組與候選值

- A是目前預測組，不列入歷史連準。
- 最近相同號碼與相同球位的歷史組為B，再往前依序為C、D、E……。
- 各組只能比對相同期距與相同球位。
- 每個歷史組以一個參照號碼對該組下 `h` 期的5個開獎號碼計算，因此每組只產生5個候選值。
- 不得先聯集全部歷史組候選值，再對全部候選值做兩兩組合。

## 鎖定1碼

- 先比較B與C的共同值。
- B與C沒有共同值即停止。
- 只有共同值可以依序延伸至D、E、F……。
- 連準4至7次有效。
- 連準達8次時整條無效，不得截短後輸出。

## 鎖定2碼

- 必須由2個值覆蓋歷史組，同一期命中2值仍只算1次連準。
- B與C沒有共同值時，以B與C合計最多10值作為候選池，繼續比對D。
- 候選池與D仍沒有共同值即停止。
- D命中B的值時，下一輪為C的5值加上B命中的值；D命中C時反向處理。
- B、C、D、E至少都要納入回推。
- 一個值若整段只出現一次，只能位於中間，不得在第一組或最後一組。
- 相同最長連準若有超過2個可延續值，整條無效，不得輸出其兩兩組合。
- 兩個值套用A得到相同預測號碼時，結果只顯示一個號碼。
- 連準達12次時整條無效，不得截短後輸出。

## 顯示與循環值

- 今彩539、天天樂加減值使用39號循環；六合彩、大樂透使用49號循環。
- 今彩539、天天樂合值範圍為1至78；六合彩、大樂透為1至98。
- 鎖定2碼的兩值與預測號碼都由小到大排列。
- 結果排序依序為連準次數、預測期、球位。
