## 27／28 權限合約

免費開關只增加七期、十三期、完整範圍、天衍、天工五項；不變更身份、付款、到期日，也不增加完整狀態、自訂狀態、複合自訂版路。購買顯示是獨立開關，控制入口與指定文案，不是停止付款後端的 kill switch。依據為 `UX-CONTRACT.md` 開頭與 `docs/PERMISSION_SWITCHES.md`。

下表假設免費開關關閉、沒有註冊試用／推薦獎勵；月季年有效，長期以 `is_lifetime` 判定。

|---|---|---|---|---|---|---|
| 訪客 | 否／否／否 | 否 | 否 | 否 | 否 | 否 |
| 免費／到期 | 七期另依 LINE 週二／五及推薦規則；十三與完整未加購權限 | 否 | 否 | 否 | 否 | 否 |

開啟免費開關後，有效已註冊會員的前三欄全部為「是」；後三欄保持原方案規則。訪客、缺會員或停用會員不獲得免費開關權限。註冊天衍48小時／天工24小時與推薦例外仍由伺服器計算。測試中的免費會員未提供 LINE ID，因此不依執行當日星期產生不穩定結果。
