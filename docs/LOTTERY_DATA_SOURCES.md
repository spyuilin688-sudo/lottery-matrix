# 開獎資料來源

## 香港六合彩

- 正式號碼來源：NFD
- 歷史日期來源：CP站
- CP站網址格式：`https://www.cpzhan.com/liu-he-cai/all-results?sort=seq&year=YYYY`
- 寫入條件：年份、期數及 7 個號碼與 NFD 同期資料完全一致。
- 儲存欄位：`period`、`drawDate`、`numbers`、`sortedNumbers`、`drawOrderNumbers`。
- 期數格式：`0YYNNN`。

## 2026-08-14 同步結果

- 2000～2026：CP站日期及 NFD 號碼可逐期核對並同步。
- 1976～1990、1997：保留既有 NFD 號碼；CP站未補入日期。
- 1991～1996、1998～1999：目前資料庫稽核未列出資料。
- 缺少或不一致的資料不寫入。
