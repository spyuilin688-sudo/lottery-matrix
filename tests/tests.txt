# Tests

## Test 1 - 號碼對照單探索設定 [sanity]
Viewport: mobile
Covers: 首頁功能入口、號碼對照單、刷新按鈕、探索設定收合
Description: 驗證號碼對照單可從首頁進入，標題操作按鈕與探索設定可正常操作。
Steps:
1. 從首頁點擊「號碼對照單」
2. 確認「刷新」與「探索設定」可見
3. 點擊「探索設定」收合，再次點擊重新展開
Expected: 號碼對照單維持開啟，探索設定可正常收合與展開，標題操作按鈕沒有重疊。

## Test 2 - 號碼對照單拒絕無效號碼
Viewport: mobile
Covers: 號碼對照單輸入驗證、01 至 49 範圍限制、無效輸入 guardrail
Description: 驗證超出合法範圍的探索號碼在失焦時被清除。
Steps:
1. 從首頁進入「號碼對照單」
2. 在第一個探索號碼輸入框輸入「50」
3. 將焦點移出輸入框
Expected: 「50」被清除，且不會自動開始探索。

## Test 3 - 連碰計算選號與清除
Viewport: mobile
Covers: 連碰立柱計算機、連碰計算、選號、清除、手機響應式
Description: 驗證連碰計算可以選取號碼並以清除按鈕恢復未選狀態。
Steps:
1. 從首頁進入「連碰立柱計算機」
2. 在「連碰計算」選取一個號碼
3. 點擊「清除」
Expected: 已選號碼恢復未選狀態，計算機仍可操作且控制項沒有超出手機畫面。

## Test 4 - 天天樂季節開獎時間
Viewport: mobile
Covers: 首頁天天樂開獎資訊卡、下一期日期時間、美西日光節約時間
Description: 驗證天天樂下一期時間由官方美西 18:30 動態換算，不使用固定台北時間。
Steps:
1. 在美西夏令期間開啟首頁天天樂資訊卡
2. 記錄下一期日期時間
3. 在美西冬令期間重複檢查
Expected: 夏令顯示台北隔日 09:30；冬令顯示台北隔日 10:30；日期隨美西開獎日正確跨日。
