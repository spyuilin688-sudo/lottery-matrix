# Tests

## Test 1 - Open Number Reference settings [sanity]
Viewport: mobile (375x667)
Covers: home shortcut navigation, Number Reference page, settings toggle
Description: Verifies that the Number Reference page opens from the home screen and its settings control can collapse and reopen the settings panel.

Steps:
1. From the home screen, tap 「號碼對照單」.
2. Verify 「刷新」 and 「探索設定」 are visible in the title area.
3. Tap 「探索設定」 to collapse the settings panel, then tap it again to reopen the panel.

Expected: The Number Reference page remains open, the settings panel collapses and reopens correctly, and the title actions remain visible without overlap.

## Test 2 - Reject invalid Number Reference input
Viewport: mobile (375x667)
Covers: Number Reference numeric input validation, invalid-value guardrail
Description: Verifies that an out-of-range lottery number is rejected when the field loses focus.

Steps:
1. From the home screen, tap 「號碼對照單」.
2. Enter 「50」 in the first exploration-number input.
3. Move focus away from the input.

Expected: The invalid value is cleared and no exploration is started automatically.

## Test 3 - Select and clear calculator numbers
Viewport: mobile (375x667)
Covers: calculator navigation, number selection, clear action, responsive controls
Description: Verifies that the collision-column calculator accepts a number selection and the clear action removes it without breaking the mobile layout.

Steps:
1. From the home screen, tap 「連碰立柱計算機」.
2. In 「連碰計算」, select one available number.
3. Tap 「清除」.

Expected: The selected number returns to its unselected state, the calculator remains usable, and the controls stay inside the mobile viewport without overlap.
