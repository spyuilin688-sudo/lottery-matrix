# Tests

## Test 1 - 快捷與 Matrix 同星結果順序 [sanity]
Viewport: mobile
Covers: 底部快捷短按、快捷設定、快捷目標導航、Matrix 同星探索結果時間方向
Description: 驗證快捷可正常進入 Matrix 同星，且探索結果由舊到新排列，最新資料位於下方。

Steps:
1. 點擊底部「快捷」
2. 若出現「快捷設定」，選擇「Matrix 同星」
3. 在 Matrix 同星執行一次探索並比較結果列表上方與下方的期數／日期
4. 再次點擊底部「快捷」

Expected: 未設定目標時顯示「快捷設定」；選擇後可進入 Matrix 同星；同星結果由舊資料往下排列到新資料，最新結果位於列表下方；再次短按可在快捷目標與原頁面之間切換。

## Test 2 - 快捷長按不誤觸短按導航
Viewport: mobile
Covers: 快捷長按三秒設定、短按抑制 guardrail
Description: 驗證長按快捷只開設定，不會在放開時額外執行一次短按導航。

Steps:
1. 長按底部「快捷」三秒
2. 放開按鈕
3. 查看目前顯示內容

Expected: 顯示「快捷設定」，且放開後不會立即跳轉到快捷目標。

## Test 3 - 通知頁手機版面不重疊
Viewport: mobile
Covers: 通知列表響應式欄位、圖示、設定按鈕、切換開關、底部導覽避讓
Description: 驗證通知頁的主要列內容在手機寬度維持同列可讀且不互相碰撞。

Steps:
1. 點擊底部「通知」
2. 查看前數筆通知設定列
3. 捲動到列表下方

Expected: 每筆通知列的圖示、標題、設定按鈕與開關均在卡片內，沒有重疊、超出或水平溢出，底部內容不被導覽遮住。

## Test 4 - 連碰立柱計算機手機操作完整
Viewport: mobile
Covers: 連碰立柱計算機頁籤、選號、清除、立柱控制、結果卡、響應式寬度
Description: 驗證計算機在手機寬度可以操作且所有主要控制不被裁切。

Steps:
1. 從首頁進入「連碰立柱計算機」
2. 在連碰頁選取號碼並使用清除
3. 切換到立柱頁並操作加減控制
4. 查看二星至五星結果卡

Expected: 頁籤、選號區、清除、立柱加減與四張結果卡均完整顯示在頁面內，沒有重疊、裁切或水平溢出。

## Test 5 - 三個工具頁不顯示除錯外框
Viewport: mobile
Covers: 歷史開獎、Matrix 同星、號碼對照單列表閱讀層級與正式容器樣式
Description: 驗證先前用於容器邊界診斷的各色 outline 已完全移除。

Steps:
1. 依序進入歷史開獎、Matrix 同星、號碼對照單
2. 開啟各頁設定卡與浮動設定卡
3. 查看頁首、內容、設定卡、列表與結果區

Expected: 三頁只顯示正式邊框與既有樣式，不出現除錯 outline；號碼對照單橫線維持原強度、直線較淡、期數與號碼層級可辨識，六合彩與大樂透最右特別號紅框降低亮度，刷新與探索設定高度縮減且水平間距為 8px。
