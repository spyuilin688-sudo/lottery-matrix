# Tests

## Test 1 - 管理員登入並修改自己的名稱 [sanity]
Viewport: desktop
Covers: AppDeploy Auth, GET /api/bootstrap, PUT /api/me/name, Supabase admin_accounts, audit_logs
Description: 驗證啟用中的管理員可登入並修改自己的名稱，重新整理後仍保留修改結果。

Steps:
1. 使用已存在於 admin_accounts 且狀態為啟用的管理員帳號登入
2. 點擊右上角自己的管理員名稱
3. 輸入新的名稱並點擊儲存
4. 在二次確認視窗點擊「確認修改」
5. 重新整理頁面

Expected: 點擊儲存後先出現二次確認，取消時不寫入；確認後右上角顯示新的管理員名稱，重新整理後名稱仍維持不變。

## Test 2 - 手機版搜尋會員並停權或啟動
Viewport: mobile
Covers: GET /api/data/users, PUT /api/members/:id/status, member search/filter, 30-row pagination, audit_logs
Description: 驗證營運管理員可在手機版列表搜尋會員、查看在線統計並切換帳號狀態。

Steps:
1. 以營運管理員進入「用戶管理」
2. 使用會員 ID、方案、推薦碼或邀請碼搜尋一位會員
3. 使用狀態選項篩選會員
4. 點擊列表中的「停權」或「啟動」
5. 檢查二次確認內容後確認操作

Expected: 列表每頁最多 30 筆，依序顯示 LINE用戶ID、註冊時間、最後上線時間、平均在線時間、狀態、驗證用戶ID及最新帳號狀態；取消二次確認時狀態不得改變。

## Test 3 - 手動管理會員訂閱
Viewport: desktop
Covers: GET /api/data/subscriptions, PUT /api/subscriptions/:id, adjustExpiry, user information dialog, 30-row pagination
Description: 驗證營運管理員可查看訂閱列表、會員資訊並調整方案到期日。

Steps:
1. 以營運管理員進入「訂閱管理」
2. 點擊一位會員的「用戶資訊」，確認顯示用戶管理內的相同資料
3. 點擊「調整到期日」，輸入日期後儲存
4. 在二次確認視窗確認修改
5. 重新載入「訂閱管理」

Expected: 列表每頁最多 30 筆，依序顯示 LINE用戶ID、訂閱方案、開始時間、到期時間、自動續訂、調整到期日及用戶資訊；用戶資訊視窗的「關閉」按鍵文字清楚可見；取消二次確認時不更新，確認後到期日依操作更新。

## Test 4 - 審核轉帳申請並套用角色統一權限
Viewport: desktop
Covers: GET /api/data/transferRequests, PUT /api/transfer-requests/:id, payments linkage, role module permissions, last-super and self-delete protection
Description: 驗證營運管理員可確認或拒絕待審核轉帳，查看人員只能查看，管理員保護規則不允許刪除自己或移除最後一位啟用中的超級管理員。

Steps:
1. 以營運管理員進入「訂閱管理」的「轉帳申請」
2. 對待審核申請點擊「確認」或「拒絕」，再完成二次確認
3. 以查看人員重新登入並開啟相同頁面
4. 以超級管理員進入「管理員權限」，確認新增、修改、刪除都先顯示二次確認，並檢查自己的刪除操作

Expected: 取消二次確認時不異動資料；確認的申請建立付款並開通方案，拒絕的申請不建立付款；查看人員沒有異動按鈕；管理員異動均先確認，且系統拒絕刪除自己及移除最後一位啟用中的超級管理員。

## Test 5 - 系統連線狀態獨立呈現異常
Viewport: mobile
Covers: GET /api/system-status, AppDeploy status, Supabase Database/Auth, Matrix status APIs, four lottery cron statuses, fault isolation
Description: 驗證進入系統設定會自動檢查所有項目，並可手動重新檢查；單一 API 異常不會清除其他項目的狀態。

Steps:
1. 進入「系統設定」
2. 查看連線狀態卡片
3. 點擊「重新檢查」

Expected: Matrix audit API 顯示異常及錯誤內容，Matrix coverage API 仍顯示正常；每張卡片顯示項目說明、最後檢查時間及回應時間。
